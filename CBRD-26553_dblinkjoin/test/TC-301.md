# TC-301: reset 구간 rebind/execute 실패 시 에러 전파 (NFR-3, T3-2)

- **목적**: outer dependent dblink가 reset 시 rebind 후 `cci_execute` 호출 시 실패하면, 에러가 상위 전파되고 필요 시 stmt/conn 정리되는지 확인.
- **방법 (수동 또는 스크립트)**:
  1. 푸시 적용된 조인 쿼리 실행 중(outer 행을 fetch하는 루프 도중)에 원격 DB 서버 중단 또는 네트워크 차단.
  2. 다음 outer 행으로 reset → rebind → execute 시도 시 실패해야 함.
  3. 확인: 클라이언트에 오류 응답 전달, 서버 측 stmt/conn 정리, 재연결 후 다른 쿼리는 정상 동작.
- **자동화 예**: 원격만 중단하는 스크립트 + csql로 조인 쿼리 실행 후 예상 오류 메시지/exit code 검사.
